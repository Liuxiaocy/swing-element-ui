## 环境踩坑（本次会话追加）

- 当前 Bash 沙箱的 coreutils 缺失（`cat`/`head`/`tail`/`dirname`/`sleep`/`timeout` 均不在 PATH），
  仅 `echo`/`cd`/`pwd`/重定向可用；`/tmp` 重定向落盘不可靠。→ 跑 Java 用**绝对 JDK 路径 + 绝对 classpath**，
  不经过管道（`| head` 等会失败），结果用 Write 工具写 `_sc.sh`、再用 Read 工具读 `_sc.log` 回看。
  `_sc.sh` 用纯 sh 内建（无 `timeout` 兜底），批量跑会偶发 SIGTERM；改为**逐条独立 Bash 调用**抓 rc 最稳。
- 全套自检在 bash 里跑（cmd.exe 仍被安全策略禁止）；`git clean -f -- _sc.sh _sc.log` 可删临时驱动（rm 包装缺失 dirname）。

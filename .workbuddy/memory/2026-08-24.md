## Bug 修复批次（提交 9588131，32 文件 +243/-70）

修复用户报告的全部 8 个演示 bug。根因分析先行（systematic-debugging），探针实测验证。

### 快速点击系统性失效（用户直觉"所有状态组件都有此问题"是对的）
两套独立机制，探针（.workbuddy/probe/RapidClickProbe.java）实测区分：
1. **Checkbox/Radio/Switch**（JToggleButton 系）：`BasicButtonListener.mouseExited` 解除 armed，
   `ToggleButtonModel.setPressed(false)` 因未 armed 跳过翻转。指针在按下与释放之间移出边界即丢点击。
   → 新增 `core/StickyToggleModel`：`setArmed(false)` 在 `isPressed()` 期间直接忽略。三组件构造器 setModel 接入。
2. **23 处 mouseClicked 依赖（20 个组件）**：AWT 合成 CLICKED 在按下与释放之间有任何移动时丢弃。
   → 全部改 mousePressed（按下即响应）。自检里 21 处程序化 CLICKED 派发同步改 PRESSED。

### 单点修复
- **AstAvatar 角标裁剪**：badge 圆心在组件 bounds 外上半被裁。边界外扩 `BADGE_PAD=12` + paintComponent
  translate 内缩，视觉直径不变。注意：离屏断言需 badge.doLayout()（FillLayout 不会自动跑）且采样点距圆心
  ≤4px（pop 动画可能停在 0.6 缩放）。
- **GlassPane 抽屉失效**：setActive(false) 的匿名 220ms 隐藏 Timer 无法取消，重激活后仍触发藏掉面板。
  → 提升为 hideTimer 字段，setActive(true) 先 stop。
- **AstLoading 全屏冻结**：新增常驻 AWTEventListener（MOUSE/MOTION/WHEEL/KEY mask），loading 期间
  FULLSCREEN 消费全部事件、WRAP 消费遮罩区域内鼠标。demo 控制按钮必须放 wrap 外。
- **AstLoading WRAP 闪烁**：不透明子组件（Progress）的 paintImmediately 绕过父 paintChildren 里的
  overlay 直接上屏 → 与 spinner 全帧交替闪烁。→ 淡入完成回调里 target.setVisible(false)（不再产生
  dirty region），hideLoading 立即恢复再渐隐。
- **AstMessage Toast**：AnimatedPopup 新增 `setDismissOnOutsideClick(false)`（Toast 定时器自灭，不参与
  外部点击关闭，否则触发按钮 MOUSE_PRESSED 打掉刚弹的 Toast）；`show()` 重挂 dismiss 监听（hidePopup
  摘除后二次展示失效）；非 EDT 分支 duration 写死 1234 的顺带 bug 修正。
- **Button 朴素模式**：硬编码 PLAIN_BG/FG 无视 hover/active。→ 底色 shade(0.93/0.84) 逐级加深 + 文字
  同步 shade(0.75) 加深 + 边框向 PLAIN_FG 收敛。**教训：加深底色会压缩对比度，PRIMARY plain hover
  只加深底色只能到 4.09:1，必须文字同步加深；过渡帧对比需单调安全**。
- **AstLoadingDemo**：控制按钮移出 wrap 范围（旧结构遮罩出现即盖住按钮 = "模式A未生效"体感）；
  openFsCustom 加 3.5s 自动关闭（全屏冻结后无退出途径会死锁）。

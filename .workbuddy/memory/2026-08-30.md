### P4-D：AstIcon 重构（d308301）
- `enum Type` 共 54 个图标；旧 int 常量 = 枚举 ordinal（旧 `AstIcon(int)` 经 `typeOf` 委托，自检锁定兼容）。
- 静态绘制器 `paintIcon(Graphics2D, Type, Color, size, spin)`：任意组件零实例复用。
- `setSpinEnabled(boolean)` 用 40ms Timer 推进 `spinPhase += PI/8`。
- 挖孔用 `AlphaComposite.Clear`（LOCATION 圆心、DELETE_FILLED 竖条），不依赖背景色。
- 新建 `AstIconDemo`（4 段：全览网格/尺寸变体/颜色变体/旋转动画）+ `--selfcheck`。

### P4-E：AstCard 阴影三态与模板（6110923）
- `enum Shadow { ALWAYS, HOVER, NEVER }`；旧 `AstCard(title, bordered, shadowOnHover)` 兼容映射（true→HOVER、false→NEVER）。
- 阴影：白卡之前画一层 `new Color(0x30,0x31,0x33, 50*factor)` 圆角，y 偏移 3px。
- 无头卡片（title 为空）：titleH=0，headerActions 隐藏，不画分隔线。
- `AstCardDemo` 补 5 类模板（阴影三态对比/图片卡/列表卡/统计三联）。

### P4-F1+F2：尺寸档位 + Badge 类型/封顶/隐藏（26fef81）
- 四组件统一 `setSize(int tier)`（SIZE_LARGE/DEFAULT/SMALL）：Pagination 按钮 32/28/24 + 字号 14/12/12；Rate 星标 30/24/18；Form 用反射找字段组件的 `setSize(int)` 下发（无则跳过）；Badge 角标高 20/18/16、红点 12/10/8。
- `AstBadge.Type` 5 色；`max` 封顶（默认 99，超过显示 `max+`）；`hidden` 开关（状态保留）。
- **修 bug**：宽文本角标（"999+"）按固定 PAD 定位会超出右边界被裁 → `cx = width - max(PAD, badgeW/2+1)`。
- AstBadge 首个 selfCheck（此前未注册 build.bat），含绘制级像素断言。

### P4-F3：AstLoading 定制化（1198d17）
- `setBgColor`（null 恢复模式默认）、`setSpinnerSize`（外径，弧线长与描边同比缩放，最小 2px）、`setDelay(ms)`（延迟期内 hide 则全程不显示，防短请求闪烁）。
- 遮罩绘制统一收进 `paintMask`。

### P4-F4：AstTransfer 文案与空态（2a537b6）
- `setTitles` / `setButtonTexts` / `setEmptyText` + 各自 getter。
- 空态用 `TEXT_REGULAR`（6.1:1），不用 `TEXT_PLACEHOLDER`（1.7:1 不达 AA）。

### 验证结果
- 原生 JDK 8 全量编译 0 错误；**36 项自检全绿**（比之前多 AstBadge 一项）。

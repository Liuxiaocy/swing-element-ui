## 1. 移除焦点环（用户决策：视觉优先）

用户反馈「不要焦点环，破坏了组件的显示效果」。P0-1 里加的焦点环撤回。

**原因复盘**：焦点环是贴合组件**外框**的 2px 主色描边（`focusRingRect` 内缩 2px 画在组件边界内）。
在小组件（Button/Checkbox）上勉强可接受，但在 `AstCalendar` / `AstCarousel` / `AstTree` /
`AstMenu` / `AstTimePicker` 等**大面积组件**上等于给整个面板描一圈边，视觉很难看。
（`AstButton` 那一处其实早前就被注释掉了——已经暴露过这个问题，但当时没推广到全库。）

**改动**：
- `AstInteractiveComponent` 删除 `paintFocusRing(Graphics2D, Shape)` / `paintFocusRing(Graphics2D, int)` /
  `focusRingRect(int)` / `isFocusVisible()`，以及 `focusVisible`、`pendingMouseFocus` 两个字段
  和它们在 doClick/mousePressed/focusGained/focusLost/setEnabled 里的赋值。
- 同时清掉因此不再使用的 import：BasicStroke / Color / Graphics2D / Shape / RoundRectangle2D。
- 删除 13 处调用：AstButton(本就注释) / Checkbox / Radio / Switch / Slider / Rate / Tree /
  Calendar / Carousel / Menu / Dropdown / CloseButton / TimePicker。

**保留**：键盘可达性本身（setFocusable、Space/Enter 键绑定、Esc 关闭归还焦点、
`assertKeyboardAccessible` 断言）与 FOCUS 动画（`focusProgress()` 被 `FrameworkDemo` 用到，不能删）。
即：**可键盘操作，但无视觉焦点提示**。

**验证**：JDK 1.8 全量编译通过；47 项 self-check 全通过；DocSnippetCheck OK（20 篇）。
无 selfCheck 断言过焦点环，所以删除不影响自检。
（另外：焦点环依赖 `isFocusOwner()`，离屏渲染拿不到焦点，所以**没法用像素断言验证**——
这类"只在真实窗口里才出现"的视觉改动只能靠跑 demo 人眼确认。）

## 4. 抽屉点击遮罩关闭（用户 bug：展开后点旁边黑半透明区要收起）

用户反馈「抽屉，展开后，鼠标点击旁边黑色半透明部分，抽屉面板收起」——原实现遮罩点击根本无反应。

**根因**：`GlassPane`（opaque=false 的 JPanel，作模态遮罩）自身**没有挂任何 MouseListener**。
AWT 的 `Component.eventEnabled()` 在组件没有带回调的鼠标监听器时会返回 false，于是落在遮罩上的
`MOUSE_PRESSED` 被**静默丢弃**。卡片内 × 有效只是因为它挂在 `DrawerPanel` 卡片上，卡片自带监听器。

**改动**（`src/org/swelement/ui/AstDrawer.java`）：
- 新增 `MouseListener maskCloser` 字段挂到 `DrawerPanel`，在 `openNew` 里给 `gp` 加
  `MouseAdapter`：`mousePressed` 时 `if (!card.getBounds().contains(e.getPoint())) card.close();`
  （卡片内部交给卡片自己处理，不拦截）。
- 因 `GlassPane` 是按 root pane 复用的（缓存在 `GP_KEY`），**关闭时必须卸载监听器**，否则旧监听器残留：
  下一次打开点遮罩会触发已被移除的卡片 close()（重复 onClosed）。两条关闭路径都加卸载：
  `closeExisting` 复用路径、`closeHandler` 滑出完成回调。
- selfCheck 第 2 步补**负向+正向**断言：派发 `mousePress(gp, inX, inY)` 点卡片内→必须仍开着；
  `mousePress(gp, maskX, maskY)` 点遮罩外→必须关闭且触发 onClosed。新增 `mousePress(Component,int,int)`
  私有静态 helper 构造 MOUSE_PRESSED（坐标相对 gp，与 `getBounds()` 同坐标系，可直接断言落点）。

**验证**：JDK 1.8 全量编译通过；`AstDrawer` self-check 输出 `AstDrawer self-check OK`（exit 0）；
随后跑全量 49 项 self-check + DocSnippetCheck，预期全绿（待汇总）。

**待办**：跑完全量后提交 `fix(ui): 抽屉点击遮罩关闭`；可选更新 assessment/CHANGELOG。
